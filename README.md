# FancyHelper 宣传视频页面

FancyHelper 的自动播放宣传页面，全屏录屏即可作为宣传视频素材。

## 文件说明

| 文件 | 说明 |
|------|------|
| `promo.html` | 主页面，12 场景自动轮播，约 57s |
| `logo.webp` | FancyHelper Logo |
| `1.mp4` ~ `5.mp4` | 占位视频（绿幕区域素材） |
| `CloudFlare.png` | CloudFlare 图标 |
| `OpenAl.png` | OpenAI 图标 |
| `DeepSeek.png` | DeepSeek 图标 |
| `Ollama.png` | Ollama 图标 |
| `More.png` | 更多提供商图标 |

## 使用方式

直接浏览器打开 `promo.html`，全屏播放后录屏。

## 视频素材替换

`1.mp4` ~ `5.mp4` 为占位文件，替换为你自己的游戏录制画面即可。视频自动播完会翻到下一页。
